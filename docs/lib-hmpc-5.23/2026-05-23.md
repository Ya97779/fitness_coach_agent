# 2026-05-23 开发日志

## 新增功能

### 饮食/运动记录编辑与删除
- 首页点击记录 → 底部弹窗编辑（食物：名称/热量/餐次，运动：全部字段）
- 左滑记录 → 露出红色删除按钮
- 后端 PATCH/DELETE 端点（`/food-log/{id}`, `/exercise-log/{id}`）
- 编辑/删除后自动同步 DailyLog 的摄入/消耗热量

### 食物热量结构化份量输入
- 记录饮食时可选择份量：数量 + 单位（克/份/碗/个/杯/盘/块/片/条）
- 克模式：查 API 每100g热量按克数换算
- 非克单位：带份量信息调 LLM 估算
- 后端异步处理：先保存记录（热量=0），后台线程调 LLM，算完自动更新

### 食物热量缓存
- 新增 `food_calorie_cache` 表，存储 API/LLM 查询过的食物热量
- 同名食物第二次记录直接命中缓存，不再重复调 API/LLM
- 支持同单位不同数量按比例换算

### 首页热量进度条
- 原圆环改为单条进度条：摄入 / 目标
- 超出目标变红，未到变绿
- 底部显示运动消耗 + 热量缺口/盈余

### 用户热量目标设置
- "我的"页面新增"每日热量调整"输入
- 负数 = 热量缺口（减脂），正数 = 热量盈余（增肌）
- 首页目标 = TDEE + 调整值

### 清除全部数据
- "我的"页面新增"清除全部数据"入口
- 删除所有饮食记录、运动记录、对话历史，保留账户信息

### 聊天页面优化
- 用户消息显示在右侧，AI 消息在左侧
- 用户头像从"我的"页面获取

## Bug 修复

| 问题 | 原因 | 修复 |
|------|------|------|
| 浮动计时器在首页不显示 | 首页无水平 padding，计时器超出可视区域 | 统一页面 padding 为 28rpx |
| ExerciseItem.notes 崩溃 | memory/stats 模块引用了不存在的字段 | 移除 notes 引用 |
| 聊天气泡都在左边 | `{{msg.role}}` 应为 `{{item.role}}` | 修复 wx:for 变量名 |
| DELETE 后页面不刷新 | request.js 只认 200 状态码 | 改为 2xx 范围 |
| 编辑弹窗不弹出 | `catchtap` 阻止了 `bindtap` 触发 | 移除同元素的 catchtap |
| 编辑弹窗事件穿透 | 缺少 catchtouchmove | 添加 catchtouchmove 阻止穿透 |
| 清除数据 500 错误 | SQLAlchemy 不允许 join()+delete() | 改为先查 IDs 再 in_ 删除 |
| LLM 估算卡住导致"计算中..." | 无超时保护 | 添加 request_timeout=30s |
| 食物热量不一致 | LLM 每次返回不同值 | 添加热量缓存表 |
| 聊天页面横向溢出 | .page 缺少 overflow:hidden | 添加 overflow:hidden |
| "计算中..."不更新 | LLM 后台算完后首页无刷新 | 添加 3 秒轮询，最多 10 次 |
| 食物编辑无法改份量 | 编辑弹窗缺少份量字段 | 添加份量步进器 + 单位 picker |
| 清除数据后无反馈 | 只 showToast，页面不跳转 | 清除成功后 switchTab 到首页 |
| remaining 变量冗余 | home.js 计算了但 wxml 未使用 | 移除 remaining 相关代码 |
